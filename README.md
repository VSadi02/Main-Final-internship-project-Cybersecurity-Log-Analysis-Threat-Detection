# Cybersecurity Log Analysis and Threat Detection System

## 📌 Project Overview

The **Cybersecurity Log Analysis and Threat Detection System** is a security-focused data analytics project developed to analyze login and access log data and identify suspicious or unusual activities.

The project uses **Python, Data Analytics, Machine Learning, and Microsoft Power BI** to process cybersecurity log data, detect anomalous login activities, and present meaningful security insights through interactive dashboards.

---

## 🎯 Objectives

- Analyze cybersecurity login and access log data.
- Clean and preprocess raw security log data.
- Identify unusual and suspicious login activities.
- Use the **Isolation Forest** algorithm for anomaly detection.
- Analyze user login and access behavior.
- Analyze network and security-related information.
- Create interactive Power BI dashboards.
- Present cybersecurity findings in an easy-to-understand format.

---

## 🔍 Project Features

- Cybersecurity log data analysis
- Data cleaning and preprocessing
- Login activity analysis
- Failed and successful login analysis
- User behavior analysis
- IP address and location analysis
- Device and browser analysis
- Network response-time analysis
- Anomaly detection using Isolation Forest
- Interactive Power BI dashboards
- Security trend and pattern analysis
